# CP/M-80 v2.2 for PC-9801 series

PC-9801シリーズ向けのCP/M-80 v2.2起動用FDイメージです。2DD/2HDの両方を用意しています。DITT.EXEなどのツールでFDに書き込んで実機で利用したり、HxCやGotekのFDDエミュレータなどで利用できます。

動作環境は、2DDまたは2HDのFDDを備えるPC-9801シリーズのノーマルモードです。NEC V30プロセッサの8080エミュレーション機能を活用していますので、稼働CPUをV30に切り替えてからブートしてください。もちろん、V30非搭載機では利用できません。PC-9801VMとPC-9801RXで動くことを確認しています。

SCSI HDDにも対応しています。ただし、DISK BIOSの新SENSEコマンドを使っているので、それに対応した機種（VM以降？）でなければ、HDDは利用できません。HDDは、セクタ長512バイトで物理フォーマットされている必要があります。物理フォーマット用のコマンドは同梱していませんので、必要ならば別環境で作業してください。

FDDは4台まで、HDD区画は2つまで利用できます。FDDに割り当てられるドライブ文字はA～Dで、HDD区画に割り当てられるのはE～Fです。HDD区画については、SCSI IDと区画番号の小さな順に有効なものを探し、最初の2つにドライブ文字を割り当てます。利用可能な区画サイズは2～128MiBです。

また、RS-232Cポートにシリアル端末を接続して利用可能です。通信速度は9600bpsに設定してください。


## 利用上の注意

処理高速化のために、ディスクキャッシュをGVRAM領域に作成して利用しています。そのため、不用意な電源断やディスク交換でファイルの変更内容が失われる恐れがあります。電源を切ったりディスクを交換したりする際には、CCPのプロンプトでCtrl-Cを入力し、再度プロンプトが表示されるまで待つようにしてください（CP/Mのウォームブート時にキャッシュを書き戻します）。

## FDFORMAT.COM

FDフォーマット用のコマンドです。

```
FDFORMAT B:
```

のようにオプションなしで実行すると、CP/M用のデータディスクとしてディスクを初期化します。CP/Mを起動可能なディスクを作成する場合には、次のように /S オプションを指定してください。

```
FDFORMAT B: /S
```

なお、/L オプションを指定すると低レベルフォーマットのみを実施します。

メディアタイプ（2DDか2HDか）は自動判別しますが、未フォーマットなメディアの場合は自動判別できません。自動判別できない場合には、/2DD または /2HD オプションを指定してください。


## HDFORMAT.COM

HDD区画フォーマット用のコマンドです。対象区画は「SCSI ID:区画番号」で指定します。

```
HDFORMAT 1:3
```

のようにオプションなしで実行すると、CP/M用のデータディスクとしてディスクを初期化します。CP/Mを起動可能なディスクを作成する場合には、次のように /S オプションを指定してください。

```
HDFORMAT 1:3 /S
```

/S オプション指定時、対象HDDに「固定ディスク起動メニュープログラム」などのマスターIPLが存在しない場合には、CP/M区画をブートするだけの機能を持つ独自マスターIPLを書き込みます。この独自マスターIPLは、HDD内のブータブルなCP/M区画をリスト表示します。番号を入力すると起動できます。「N」を入力すると次以降のHDDにある独自マスターIPLにchainします（なければ停止します）。

固定ディスク起動メニュープログラムがすでに書き込まれている場合は、そのメニューを使ってCP/M-80を起動可能です。

## FDISK.COM

HDD区画の作成や設定、削除に使うコマンドです。対象HDDはSCSI IDで指定します。

```
FDISK 1
```

起動後の操作は、Linuxのfdiskコマンドに合わせてあります。pで区画情報の表示、nで区画の新規作成、bで起動フラグの設定、dで区画の削除が可能です。変更した区画情報はwでHDDに反映できます。コマンドの終了はqです。区画サイズは、MiB単位で指定します。設定可能な数値は「2」から「128」までです。

xを入力すると、HDDのマスターIPL領域をゼロ埋めします。独自マスターIPLを削除したい場合などに利用してください。

## diskdefs

cpmtoolsで利用可能なディスク定義ファイルです。cpmtoolsでCP/Mのイメージファイルを作成、操作する場合に利用します。2DD用と2HD用の設定を記述しています。

## 余談

V30の8080エミュレーション機能を使いたかったので作ってみました。V20-MBCを作ったときにも思いましたが、この頃のVシリーズにはロマンがありますね。μPD9002も使ってみたいですが、動く状態の88VAは入手が難しそう。

先にCP/M-86を移植したおかげで割とすんなり作れましたが、CP/M-80 v2.2のCCPは起動ディスクをA:と決め打ちしており、そこにどう対処するかで悩みました。

マスターIPLは当初、NECの「固定ディスク起動メニュープログラム」にチェイン可能にする予定でした。チェイン自体は問題なくでき、固定ディスク起動メニュープログラムでCP/M区画をブート可能だったのですが、なぜかその場合、MS-DOS区画がブートできなくなります。チェイン時に0000:0584にドライブ情報を書いているのですが、MS-DOSのブートには何かほかの情報も必要みたいです。謎が解けないままだと不可解な動作になるので、CP/M用のマスターIPLにだけチェインするようにしています。
